# Simple Calculator for Android

A clean, dark-themed calculator with addition, subtraction, multiplication, division, decimals, percent, sign toggle, clear, and backspace.

## Download the APK

[**Download the latest Android APK**](https://github.com/average-codex/test/releases/download/calculator-latest/app-debug.apk)

The APK is built automatically by GitHub Actions on every push to main. If the release is not available yet, check [Actions](https://github.com/average-codex/test/actions) for build status and download the **SimpleCalculator-APK** artifact from a successful run.

## Build

The GitHub Actions workflow uses Java 17, Android SDK 35, Android Gradle plugin 8.7.3 and Gradle 8.9. No PC or local Android Studio required.

For a local build: `gradle assembleDebug` with Android SDK 35 installed.

## Source

- Java native Android Activity, no external UI dependencies
- Minimum Android version: Android 7.0 (API 24)
- No account, ads, or network permissions
